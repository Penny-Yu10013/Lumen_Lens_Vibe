## M9b 厚牆實作（結論 → 程式，對照科研報告 §7）

| 結論 | 實作位置 |
|---|---|
| 紋帶＝圓角七邊形板段，板段內法向常數 | `ngonSD()`（`shapeSD` 上方，iris 限定）：iq 式正 N 邊形 SDF 回傳距離＋向外法向＋板段索引；`irisWarp()` 低頻不對稱。`#define NG 7.0 / IRIS_ROT 0.0（頂邊平、底頂點、對稱於 y 軸）/ IRIS_R / IRIS_RR / IRIS_A / IRIS_ANISO / IRIS_PAR` |
| 外形＝最外層紋帶 | `shapeSD`＝`ngonSD`＋0.03 fbm 邊緣凹凸 |
| 內層越圓 | `inw=smoothstep(0.55,0.15,zr)*0.7`：紋帶座標與法向一起往圓混 |
| 彩虹只在中環／外環 | `r1`(0.30–0.45)、`r2`(0.60–0.85)；過渡灰帶 `tr`(0.46–0.59) 更灰藍；邊帶 `eb`(0.87+)；`gate=ring*(1-crust)`；核由 `bandAmp` 歸零 |
| λ＝d_eff·\|sv\| 厚薄通用 | 保留；`pitchVar` 每層自己的週期（只隨帶座標變）；`uDGrad` 預設 0.35（兩環同傾角同時出彩） |
| 厚度→Bragg 選擇性（三處接線） | `tk=smoothstep(0.3,1.6,uThickness)`：①二級 `0.30*(1-0.8*tk)` ②去飽和 `mix(0.35,0.05,tk)` ③增益 `mix(0.5,1.3,tk)` |
| 零級耗竭（施工中新增，報告未列） | `T*=1-0.75*irisW*mix(0.3,1.0,tk)`：直透白光在出彩處被彎走→彩虹「取代」本體亮度而不是淡染（probe：沒有這項色差只有 +40） |
| 粗帶牆體視差 | 沿視線兩點採樣：出射點 `q`、入射點 `q2`（Snell n=1.54，退 `T·tanθ_in·IRIS_PAR`），分區項取平均；每板段常數牆傾角→邊界軟化寬 `ew` |
| 側壁 | 平面版 main `#ifdef SLICE_IRIS`：頂輪廓外、底輪廓（往 `vL.xy/vL.z·IRIS_PAR·uThickness` 平移，上限 0.08）內＝牆；霧面糖粒 `vnoise(p*90)`、亮度 `1.1+1.2u`、頂緣琥珀 |
| 彩虹＝透射 | `irisAdd*=uBacklight`；前光只驅動平面版 sheen |
| UI 光暈同步 | `[SEC:GLOWCOLOR]` `spectralJS(d0*sv)`（頂板段法向＝+y，與 shader 同式） |

預設值變更（`[SEC:SLICES]`）：uThickness 0.8→1.2、uD0 1300→1100（滑桿 700–2400）、uDGrad 0.9→0.35。無新增 uniform／滑桿。

## 程式地圖

- 本體＝`[SEC:GLSL]` `FRAG`：`ngonSD/irisWarp/shapeSD`（`#ifdef SLICE_IRIS` 外形區）→ `sliceLinear` 的 `SLICE_IRIS` 段 → 平面版 main 的側壁段。光暈同步在 `[SEC:GLOWCOLOR]`；滑桿定義在 `[SEC:SLICES]`。沒有 DOME 區塊（iris 不做蛋面）。
- 驗證要點：headless Chrome 截圖時 iris shader 最慢（見總表第 1 節 `--virtual-time-budget` 註記）；本版 fbm 減半後應有改善。
