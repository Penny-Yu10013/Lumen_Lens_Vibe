## v2 批改 → v3 施工（2026-09-07 第二輪，錨點 iris_9_f01＋日光對照 iris_1）

用戶總結：「不管日光背光還是黑幕背光都有很大一部分是真透明、透到背景色；黑線邊不多，表現是溫潤的漸層跟刺激的虹彩色帶。」→ 模型改成**透明體＋染色＋彩虹層**三層。

| # | 用戶批改（部位｜錨點｜現況） | v3 改動 |
|---|---|---|
| 1 | 本體透光｜亮度接近光桌、黃綠是染色｜不透的橄欖綠塊 | sigma 大幅下修：本體 (0.22,0.08,0.50)（吸藍＞吸紅≫吸綠＝選擇性染色）、核 (0.06,0.14,2.0)；`profile` 對 iris 改 0.92–1.0（共用暗角太重）。規則：本體任一點 ≥ 光桌 60% |
| 2 | 裂紋｜看不到線，只有錯位＋淡影｜明顯暗線 | 暗線移除（`irisBand` 只回傳 `crackSoft`＝寬羽化弧長 0.05），透光 −6%；錯位靠板段半平面座標天然保留 |
| 3 | 粗帶｜更橄欖、透光少一點、漸層邊｜硬邊深色條紋 | 節奏剖面改餘弦峰 `cs=pow(0.5+0.5cos,1.4)`；粗帶＝透光 −22%（中性乘法）＋sigma 加 (0.10,0,0.25) 更橄欖；過渡帶 −12%、邊帶 −15% |
| 4 | 彩虹邊緣｜帶內色相漸變、跨 2–3 帶淡出、暈進隔壁｜硬切＋黑縫 | 徑向包絡＝粗帶餘弦反相 `(1-cs)`（跨帶柔化）；細帶只做 20% 質地；**零級耗竭綁 `vis`（可見光譜能量）**——λ 在可見光外時不耗竭＝黑縫根除 |
| 5 | 彩虹分佈｜同扇區只有部分板段出彩、相鄰柔淡出、一塊一塊｜整扇區條紋化 | 每（板段 k, 細帶包 pi）一個活性 `act=smoothstep(0.3,0.7,hash)`，於粗帶內交叉淡入淡出；角向 `aw` 在扇區邊界/子裂紋柔淡出；每塊 pitch 微差 ±5%（同傾角不同塊不同色） |
| 6 | 核區｜暖黃白、全片最亮｜偏中性 | 核 sigma 藍壓到 T≈0.25（tonemap 前不夠黃壓完就白）＋tonemap 前加暖光 `pow(1-coreK,1.5)*0.6*(1,0.85,0.45)`，中心最亮往外淡 |
| 7 | 黑邊總則｜只有皮與包裹體近黑｜多處黑邊 | probe 網格驗收（下表）；皮寬縮到 sd −0.06（錨點 ~3% 半徑）；包裹體 `1-0.95·pit` |

## M9b 架構（v1 立、v2/v3 沿用）

| 結論 | 實作位置 |
|---|---|
| 紋帶＝板段，板段內法向常數 | `irisSector`/`irisBand`（`#ifdef SLICE_IRIS` 外形區）；`#define NG 7.0 / IRIS_A / IRIS_RC / IRIS_ANISO / IRIS_PAR` |
| 外形 | `shapeSD`＝七邊形∩圓＋fbm |
| λ＝d_eff·\|sv\| 厚薄通用 | 保留；`pitchVar` 每層自己的週期；`uDGrad` 預設 0.35 |
| 厚度→Bragg 選擇性（三處接線） | ①二級 `0.30*(1-0.8*tk)` ②去飽和 `mix(0.30,0.0,tk)` ③增益 `mix(0.5,1.3,tk)`；耗竭深度也隨 tk |
| 零級耗竭 | `T*=1-0.85*irisW*vis*mix(0.4,1.0,tk)`：彩虹「取代」本體亮度而不是淡染；**乘 vis** 才不會在不可見 λ 處留黑縫（v3） |
| 粗帶牆體視差 | 沿視線兩點採樣（Snell n=1.54，退 `T·tanθ_in·IRIS_PAR`），節奏/環包絡取平均 |
| 側壁 | 平面版 main `#ifdef SLICE_IRIS`：頂輪廓外、底輪廓（平移 `vL.xy/vL.z·IRIS_PAR·uThickness`，上限 0.08）內＝牆 |
| 彩虹＝透射 | `irisAdd*=uBacklight`；前光只驅動 sheen |
| UI 光暈同步 | `[SEC:GLOWCOLOR]` `spectralJS(d0*sv)` |

預設值（`[SEC:SLICES]`）：uThickness 1.2、uD0 1100（滑桿 700–2400）、uDGrad 0.35、uIrisGain 1.3。無新增 uniform／滑桿。fbm 每像素 3（shapeSD 1＋漣漪 1＋核霧 1），側壁像素 2；另 `shapeSD` 內 7 次 dot（便宜）。

## 程式地圖

- 本體＝`[SEC:GLSL]` `FRAG`：`irisNrm/irisApo/irisSector/irisBand/shapeSD/spectralN`（`#ifdef SLICE_IRIS` 外形區）→ `sliceLinear` 的 `SLICE_IRIS` 段 → 平面版 main 的側壁段（磨邊亮線對 iris 關閉）。光暈同步在 `[SEC:GLOWCOLOR]`；滑桿定義在 `[SEC:SLICES]`。沒有 DOME 區塊（iris 不做蛋面）。
- 驗證要點：headless Chrome 截圖時 iris shader 最慢（見總表第 1 節）；本版 fbm 減半後應有改善。
