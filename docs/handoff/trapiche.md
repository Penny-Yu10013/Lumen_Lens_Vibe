# 達碧茲蛋面交接（trapiche）

- **定位**：達碧茲（id:'trapiche'，標本卡第一位）＝生長結構現象；蛋面版含六臂 V 溝、透射貓眼、實體六壁核柱、核尺寸滑桿。
- **目前版本**：v6.1（V 溝去玻璃感），已推 GitHub Pages（commit e485cc5）。
- **下一步**：無待辦，用戶驗收通過（達碧茲本體滿意）；後續只接用戶截圖標註批改。

> 蛋面共用機制（DOME 折射、色散、前光、法線雙軌制、形體陰影、截圖驗證）見 `dome-shared.md`；總表在專案根 `CLAUDE.md`。
